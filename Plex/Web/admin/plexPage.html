Export federated content to Plex

This writes each federated movie/episode as a tiny .strm text file containing its stream URL on every refresh. Nothing is downloaded — Plex scans the file like any other video, but streams through the same authorized relay used for every other federated play. Point a Plex library at <path>/Movies and/or <path>/Shows. The folder must also be reachable (read-only is enough) from wherever Plex runs.
