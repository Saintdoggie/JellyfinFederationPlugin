1 Import from a Jellyfin friend

Paste a connect code from their Jellyfin Federation Companion tab. Choose which of their shared libraries to import. Plex needs the media mount below to analyze video/audio and play these titles; a catalog or a .strm link alone is not playable media.

🔒The long-lived Jellyfin credential stays inside Companion. Plex receives only a stable link cryptographically bound to one exact movie or episode.
Set up playable media in Plex

Do this once on the Plex machine. Keep Companion and the mount running while Plex scans or plays. For Docker, share the mounted folder with both containers.

Plex and Companion on the same Windows computer: install WinFsp and rclone once. Put rclone.exe beside Companion or on PATH. Run Companion with the same Windows account as Plex.

Companion manages this mount and restores it after restarting. Then choose Add to Plex below.

Manual mount, separate machines, or Docker
  1. Install rclone and its mount requirements (WinFsp on Windows, FUSE on Linux/macOS).
  2. Save this on the Plex machine. It grants read access to imported media; keep it private.
  3. In that folder, run the command for your system. Use an empty folder on Linux/macOS, or an unused drive letter on Windows. rclone mount companion: /path/to/empty-folder --config companion-rclone.conf --read-only --vfs-cache-mode full --vfs-cache-max-size 2G --dir-cache-time 30s rclone mount companion: X: --config companion-rclone.conf --read-only --vfs-cache-mode full --vfs-cache-max-size 2G --dir-cache-time 30s
  5. Choose Add to Plex on your friend below. Plex will scan the video files and detect their audio/video tracks. Existing libraries made from .strm files are left in place; remove those old library entries in Plex after verifying the new Streaming library.
