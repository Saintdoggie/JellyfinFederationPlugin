What Companion does on this computer

Companion keeps sharing and imports available in the background. Closing the window leaves it running; use Exit Companion to stop it.

Permissions, downloads and saved data
  • Plex sign-in: contacts plex.tv and your selected Plex server; saves access tokens and sharing choices privately beside the app. Tokens are sensitive and are not encrypted by Companion.
  • Media folder (optional): Set up media folder enables rclone, downloaded from rclone.org if missing, and a read-only mount. On Windows it can download the pinned WinFsp driver from GitHub and ask for administrator permission. Linux needs FUSE; system permissions are yours to configure.
  • Disk and network: playback uses your connection and a local media-cache folder with a 2 GB cleanup target. Open files can exceed that target. Idle catalog sync runs every 30 minutes.
  • Remote access (optional): Tailscale Funnel exposes Companion's relay publicly. Owner actions still require the owner key; friends get separate revocable access. Configure Funnel only when you want remote sharing.
  • Start at sign-in (optional): writes a startup entry for your user only. You can switch it off below.
  • Updates: checks GitHub when you open the dashboard; installs an update only when you request it. Diagnostics stay in a rotating local log.

Windows builds are unsigned. SmartScreen may report an unrecognized app. A Defender malware detection needs investigation; do not disable protection or add blanket exclusions. See the permissions and verification guide.

✓ Owner access

Companion's public listener is locked so strangers cannot change your sharing choices. Paste the owner key (Windows: right-click the tray icon → Copy owner key; Linux: printed at startup), or open the dashboard URL with #access=… attached.

Advanced: manual mount, separate machines, or Docker

Only needed when Companion and Plex are not on the same computer. For Docker, share the mounted folder with both containers.

  1. Install rclone and its mount requirements (WinFsp on Windows, FUSE on Linux/macOS).
  2. Save this on the Plex machine. It grants read access to imported media; keep it private.
  3. In that folder, run the command for your system. Use an empty folder on Linux/macOS, or an unused drive letter on Windows. rclone mount companion: /path/to/empty-folder --config companion-rclone.conf --read-only --vfs-cache-mode full --vfs-cache-max-size 2G --dir-cache-time 30s rclone mount companion: X: --config companion-rclone.conf --read-only --vfs-cache-mode full --vfs-cache-max-size 2G --dir-cache-time 30s
  5. Choose Add to Plex on your friend below. Plex will scan the video files and detect their audio/video tracks. Existing libraries made from .strm files are left in place; remove those old library entries in Plex after verifying the new Streaming library.
