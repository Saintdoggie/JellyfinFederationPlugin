Upload budget

Cap what this server commits to streaming out, split across however many people are watching right now - so a friend's request for more bitrate than your upload actually has spare never gets promised in the first place. This drives Jellyfin's own "Internet streaming bitrate limit," so it also governs local household streaming, not just federation traffic.
