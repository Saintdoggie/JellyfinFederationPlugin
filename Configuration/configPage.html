people People

Servers you're connected with. Manage a friend to control what they can see of your library, put them in a pool, or tweak connection settings.

hub Pools

A pool is a named group of Federation servers who all federate with every other member, not just you. Create a pool and invite servers into it - each invite still goes through the normal friend request, so every server's admin has to accept before it connects to anyone. To add a friend you're already connected to, use their entry under People above.

Each library you check appears on this server as a virtual library. Libraries with the same name on different servers are merged into one — duplicates are combined automatically.

Advanced settings

Leave blank to auto-detect from whoever is asking. Set it if any server uses Proxy mode: syncing runs in the background with no incoming request to auto-detect from, so without it the relay URL cannot be written onto items and they keep streaming directly instead — Proxy appears to do nothing at all. This is what friends and clients connect to — it's not used for this server's own Proxy streams, see below.

Where this server's own transcoder fetches a Proxy-mode stream from — never the public URL above, since that would send every byte of a stream out through a reverse proxy/VPS/tunnel and back in just to reach itself. Leave blank; loopback is correct for virtually every setup. Only set this if 127.0.0.1 genuinely isn't reachable from where ffmpeg runs (e.g. Jellyfin split across containers without a shared network namespace) or Jellyfin listens on a non-default port.

When on: your friends can see who your other friends are, and this server automatically sends friend requests to friends of your friends it discovers that way (they still have to accept). Off by default - this is a bigger trust decision than a single direct friendship. Either way, a server only ever shares its own library, never content that was itself federated into it from somewhere else.

To keep a permanent local copy of a federated item, use the download button on that item's own detail page — it downloads in the background with its own progress indicator there.

Diagnostics

Saves the advanced settings above and your library selections on the Libraries tab together - it's the same save action either tab's button triggers.

Hidden items (0)

Items you've hidden from your own local library using the "Hide" button on an item's detail page. This only affects what you see here - the friend sharing it is never notified and keeps sharing it normally. Unhiding an item does not bring it back immediately; it reappears on the next sync (or click "Provision libraries" above).
