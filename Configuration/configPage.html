Friends

Connect to another server running Federation without copying an API key by hand. Enter their address, send a request, and once they accept, both servers add each other automatically.

1 · Connect your servers

Add each remote Jellyfin server with its address and an API key (Dashboard → API Keys on that server).

New servers are tested automatically when added. Defaults work out of the box — streaming mode and other dials live under each server's "Connection details" below.

Editing a connected server's details below saves automatically, field by field — there's no separate save step for those.

2 · Choose what to share

Each library you check appears on this server as a virtual library. Libraries with the same name on different servers are merged into one — duplicates are combined automatically.

Custom virtual libraries (advanced)

Only needed if you want to hand-pick sources, merge libraries with different names, or tweak media types yourself. These are never touched by the picker above.

This button saves your library selections and the advanced settings below. Server connections in step 1 already saved themselves as you edited them.

Advanced settings

Leave blank to auto-detect from whoever is asking. Set it if any server uses Proxy mode: syncing runs in the background with no incoming request to auto-detect from, so without it the relay URL cannot be written onto items and they keep streaming directly instead — Proxy appears to do nothing at all.

When on: your friends can see who your other friends are, and this server automatically sends friend requests to friends of your friends it discovers that way (they still have to accept). Off by default - this is a bigger trust decision than a single direct friendship. Either way, a server only ever shares its own library, never content that was itself federated into it from somewhere else.
