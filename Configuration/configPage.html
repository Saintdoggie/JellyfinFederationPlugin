Pools

A pool is a named group of Federation servers who all federate with every other member, not just you. Create a pool and invite servers into it - each invite still goes through an accept step, so every server's admin has to agree before it joins anyone's pool, whether they're a brand new contact or already a friend. To invite a friend you're already connected to, use their entry under People above.

Tailscale gives this server a private address reachable from anywhere, without port-forwarding. Funnel then exposes that address to the public internet so friends can actually connect - access past that point is still gated by this plugin's own friend-token system, the same as any other connectivity choice.

Share your Plex library with a Jellyfin friend

Have a Jellyfin friend whose Federation Companion app generated a connect code for you? Paste it below to add their Plex server as a source - the same as any other federated library, just backed by Plex instead of Jellyfin.

No Companion app on their end - just a Plex server address and a token? Add it directly instead.

Let a Plex friend import from you

Generate a connect code for a Plex-owning friend to paste into their own Federation Companion app. Their Companion instance pulls whatever you share below and keeps it in sync automatically - Plex never talks to this server directly, and no Plex credential of theirs ever reaches you.

Discovery

See who else your friends are already federated with. This asks each of your current friends for their own friends list - it never contacts anyone you're not already connected to, and nobody is added automatically. A friend only shows up here if they've turned on "Allow friends-of-friends" under Advanced settings themselves.

Catalog

Browse your own library by cover art and choose what NOT to share - with everyone, with one friend, or with just one of their users. This is the opposite direction from the Libraries tab above, which controls what you pull in from friends. Federated items (things you're already watching from a friend) don't appear here - they were never yours to share onward.

Custom virtual libraries (advanced)

Only needed if you want to hand-pick sources, merge libraries with different names, or tweak media types yourself. These are never touched by the picker above.

This button saves your library selections and the advanced settings below. Sharing, pools and per-friend connection details above already save themselves as you edit them.

Advanced settings

Leave blank to auto-detect from whoever is asking. Set it if any server uses Proxy mode: syncing runs in the background with no incoming request to auto-detect from, so without it the relay URL cannot be written onto items and they keep streaming directly instead — Proxy appears to do nothing at all. This is what friends and clients connect to — it's not used for this server's own Proxy streams, see below.

Where this server's own transcoder fetches a Proxy-mode stream from — never the public URL above, since that would send every byte of a stream out through a reverse proxy/VPS/tunnel and back in just to reach itself. Leave blank; loopback is correct for virtually every setup. Only set this if 127.0.0.1 genuinely isn't reachable from where ffmpeg runs (e.g. Jellyfin split across containers without a shared network namespace) or Jellyfin listens on a non-default port.

Cloud badge on federated media artwork

Off by default. Add the badge when you want an at-a-glance source marker on movie, show, and list artwork; remove it any time. This does not change playback or sharing.

When on: your friends can see who your other friends are, and this server automatically sends friend requests to friends of your friends it discovers that way (they still have to accept). Off by default - this is a bigger trust decision than a single direct friendship. Either way, a server only ever shares its own library, never content that was itself federated into it from somewhere else.

When on, this page checks your own locally-owned movies/episodes against the matching copy on a federated friend's server (matched the same way merging above matches "the same movie" across servers) and, every time you open this page, shows a review list of any where a friend's copy is meaningfully better - higher resolution, or a clearly higher bitrate at the same resolution. Nothing is ever removed automatically - the review list just offers a "download the better copy, then remove the old one" suggestion per item. Suggestions alone never download or delete anything.

This still does not replace anything automatically. Every movie gets its own review and its own “Yes, replace this exact movie” confirmation. The old file is touched only after the new download completes and validates.

Manage exceptions (titles never suggested)

To keep a permanent local copy of a federated item, use the download button on that item's own detail page — it downloads in the background with its own progress indicator there.

Plex has no plugin system for browsing a remote catalog the way this plugin does for Jellyfin, so this writes each federated movie/episode as a tiny .strm text file (just its stream URL) under the path below, on every refresh. Nothing is downloaded — Plex scans the file like any other video, but streams from the URL inside it, through the same relay used for every other federated play. Point a Plex library at <path>/Movies and/or <path>/Shows. Requires that folder to also be reachable (read-only is enough) from wherever Plex runs — e.g. a shared host mount.

Hidden items (0)

Items you've hidden from your own local library using the "Hide" button on an item's detail page. This only affects what you see here - the friend sharing it is never notified and keeps sharing it normally. Unhiding an item does not bring it back immediately; it reappears on the next sync (or click "Provision libraries" above).
